# ✨ PihuConnect AR

An interactive hand-tracking AR experience built using MediaPipe Hands, JavaScript, HTML5 Canvas, and real-time visual effects.

This project transforms hand movements into dynamic neon animations, particle effects, lightning interactions, and immersive audio-reactive visuals directly inside the browser using webcam input.

---

# 🚀 Features

* Real-time hand tracking using MediaPipe
* Multi-hand gesture detection
* Neon glow visual effects
* Interactive particle system
* Lightning and ripple animations
* Dynamic theme switching
* Audio-reactive experience
* Cyberpunk-inspired UI
* Fully browser-based AR interaction
* No external software required

---

# 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* MediaPipe Hands
* Canvas API
* Web Audio API

# 📸 Experience Includes

# ▶️ How To Run Locally

## 1. Clone or Download the Project

```bash
git clone https://github.com/yourusername/pihu-connect-ar.git
```

OR download the ZIP file.

---

## 2. Open Project Folder

```text
pihu-connect-ar
```

---

## 3. Start Local Server

Using Python:

```bash
python -m http.server 8000
```

---

## 4. Open in Browser

```text
http://localhost:8000
```

---

## 5. Allow Camera Access

Click:

```text
Enter Experience
```

and allow webcam permissions.

---

# ⚠️ Important

Do NOT open `index.html` directly in the browser.

The webcam functionality only works when the project is served through a local server.
